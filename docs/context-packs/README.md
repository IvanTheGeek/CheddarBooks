# Context Packs

Context packs are read-optimized startup bundles for a specific area of work in this repo.

They are meant to help a contributor orient quickly without pretending to replace the underlying source docs.

## What They Are For

- fast startup for one concern
- local onboarding for one tool app
- focused bundles for humans or AI agents

## What They Are Not

They are not:

- the deepest source truth
- canonical historical record
- a replacement for requirements, workflows, or code

They are views.

They should stay linked to stronger local sources.
