# LaundryLog Event Modeling Inspiration

This note records the current inspiration surfaces for the LaundryLog Event Modeling board work.

## Current Rule

Use these surfaces as inspiration, not as the current semantic source of truth.

For LaundryLog right now:

- the durable Event Modeling notes in this repo carry the current intended meaning
- Penpot carries the live visual projection
- historical HTML experiments and mockups are comparison material

If an inspiration surface disagrees with the local Event Modeling notes, follow the local notes and fix the projection explicitly.
