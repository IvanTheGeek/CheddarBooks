# Package References

This area holds short local reference notes for external packages that matter to repeated work in `CheddarBooks`.

This repo inherits the broader package-guidance rule from `NEXUS-EMERGING`:

- official package docs first
- local package notes second
- local overrides only when this repo has stronger package-specific workflows or gotchas

These notes should stay practical.

Use them to record:

- what the package is used for in this repo
- which official docs should be checked first
- the exact local scripts, tests, and workflows that rely on it
- local gotchas that later contributors should not have to rediscover
