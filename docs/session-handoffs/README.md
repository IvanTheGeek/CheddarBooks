# Session Handoffs

Session handoffs are small operational continuity notes for this repo.

They help one human or AI contributor hand work to the next without pretending every temporary note is durable app doctrine.

## Good Uses

- current branch and task note
- next likely step
- local blockers
- reminder links to the real docs, code, or tests that matter next

## Not Durable By Default

Session handoffs are not automatically:

- requirements
- architecture doctrine
- permanent app memory

If a handoff reveals a learning that should guide future work, promote it into the proper durable doc instead of leaving it only here.
